How do AI agents use a business website?

An AI agent uses a business website the way a person does, on a person's behalf: it opens the pages in a real browser, reads them, clicks, fills in forms, and reports back or finishes the task. OpenAI introduced ChatGPT agent on July 17, 2025, with a visual browser, a text-based browser, and a terminal. Anthropic's hosted browsers announce themselves with a Claude-Agent token. For a business, the agent is the buyer's errand runner. It arrives with a job to do, such as finding a plumber who can come Thursday or booking a consultation, and it either finishes that job on your site or moves on to a competitor's.

How is an agent different from a crawler?

By the job it does and the time it does it. The AI companies now run three kinds of traffic, and each one asks something different of a site:

  • Crawlers: bots such as OAI-SearchBot, Claude-SearchBot, and PerplexityBot fetch pages on a schedule to build the index that AI answers are assembled from. The AI crawlers guide covers them.
  • Fetchers: ChatGPT-User, Claude-User, and Perplexity-User read one page at the moment a person asks a question that needs it.
  • Agents: a full browser, operated by a model, that works through a site to complete a task: comparing service pages, checking availability, filling in an inquiry form, starting a booking.

Anthropic draws the same line in its own documentation. It describes its agentic browser traffic as separate from its crawlers and fetchers, and says a site's preferences for the crawlers and fetchers are independent of it. Allowing or refusing the agent, Anthropic says, controls whether users can have Claude complete tasks on a website. A site can be fully indexed for answers and still lose the errand, because the errand happens in the browser.

How do agents identify themselves?

Each company has chosen its own signal, and the signals are still settling:

  • Anthropic: its hosted browser sends the browser's ordinary User-Agent string with the token Claude-Agent added, for example compatible; Claude-Agent/1.0. Anthropic says to match on that token, publishes the browser's IP addresses at claude.com/.well-known/sail, and recommends updating firewall rules from that file automatically. It warns that anyone can send the same header, so the IP check is what confirms the visit.
  • OpenAI: developer Simon Willison observed in August 2025 that ChatGPT agent's requests carry a Signature-Agent header naming chatgpt.com, with Signature-Input and Signature headers beside it. That is HTTP Message Signatures, the method an IETF working group is standardizing for automated traffic under the name Web Bot Auth.
  • Web Bot Auth: the signing approach Cloudflare described in 2025, in which the agent signs each request with a private key and tells the site where to fetch the matching public key, so a site can verify the sender cryptographically instead of trusting a header.

The practical reading for a site owner: look for the Claude-Agent token and for Signature-Agent headers in the server logs, verify them against the published keys and addresses, and treat a verified agent as a buyer's visit.

What does an agent need from a business site?

Everything a careful first-time visitor needs, stated in a form software can read without guessing:

  • Facts in text: the services, the service area, the hours, and how to book, written as text on the page. A phone number inside an image or hours inside a PDF are facts the agent reports back as unknown.
  • Labeled controls: buttons that say what they do, links that are real links, and form fields with visible labels. A field labeled only by placeholder text that vanishes on click leaves the agent guessing what goes in it.
  • Forms that finish: standard inputs, clear required fields, an error message that names the problem, and a confirmation page that says the inquiry was received. The confirmation is what the agent shows the buyer as proof.
  • Availability without an account: a booking page that shows open times before asking anyone to register lets the agent compare you with the next business on its list. A wall that demands an account first sends the comparison elsewhere.
  • A path with few gates: a contact form behind a challenge page or a CAPTCHA stops the agent at the door and hands the task back to the buyer, who often takes it to the competitor whose form went through.
  • Stable pages: service pages that keep their URLs, so the page an agent found last month is the page it finds today.

The accessibility work a site does for people serves agents too. Headings in order, labeled fields, descriptive link text, and alt text are the structure screen readers depend on, and they are the same structure software reads when it operates a page.

Should a business block AI agents?

A business that sells to the public should serve them, because an agent on a service page is a buyer who sent it. Blocking the agent blocks the errand, and the buyer learns only that your site was the one that failed. The cost of serving them is small: an agent that fills in an inquiry form produces one inquiry, the same as the buyer would have.

The real risks are abuse and load, and the answer to both is verification. Rate-limit by behavior, verify the agent's identity against the published addresses and keys, and refuse what fails the check. A blanket rule that challenges every automated visitor catches the verified agents along with the scrapers, and the logs will show it as a run of challenge pages served to Claude-Agent.

OpenAI built a checkpoint into its own agent: ChatGPT requests permission before taking actions of consequence, and a user can take over the browser to log in on any website. A purchase or a booking made by an agent still passes through the buyer's approval.

How do you test a site for agents?

Give an agent the buyer's errand and watch. A four-step test, run on the questions that bring the business revenue:

  • State the task the way a buyer would: find a licensed electrician in Arlington who can install an EV charger next week, and request a quote.
  • Run it in two agents: ChatGPT agent and Anthropic's Claude, starting from a plain request with no link to your site.
  • Record where each one stops: the page it reached, the field it could not fill, the gate it could not pass, and what it told the buyer about your business.
  • Fix in order: gates first, then missing facts, then forms, then rerun the same task and compare the record.

The record is the evidence. An agent that reaches your form and stops at a challenge page has told you exactly what to change, and the same test, rerun, shows whether the change worked. The measurement guide sets out how to keep that record over months.

Frequently asked questions

Do AI agents follow robots.txt?

Anthropic manages its agentic browser separately from its crawlers and fetchers, and says a site's crawler preferences are independent of it. It identifies the browser with the Claude-Agent token and published IP addresses. Treat agents as user traffic, governed at the firewall by verified identity, and keep robots.txt for the crawlers.

Can an AI agent buy something or book an appointment on my site?

Yes, with the buyer's approval. OpenAI says ChatGPT requests permission before taking actions of consequence, and a user can take over the browser to log in. A site that lets a person book without friction lets an agent book the same way, with the buyer confirming.

How do I see AI agent visits in my analytics?

In the server logs. Agents run real browsers, so they can load the same pages and scripts a person does and appear in analytics as ordinary sessions. The Claude-Agent token in the User-Agent string and Signature-Agent headers in the request identify them in the logs.

What is agentic experience optimization (AXO)?

The name some vendors give to making a site usable by AI agents. The work underneath is the list in this guide: facts in text, labeled controls, forms that finish, and no needless gates. The AI search glossary defines AXO, AAIO, and the related terms.
